PHASE III

Searching and sorting

Linear search

Checks each menu record in sequence. Works even when records are not sorted.

Worst case: O(n)

Binary search

Searches a sorted list by repeatedly halving the search range.

Typical case: O(log n)

Insertion sort — current prices, low to high

{% for price in prices %} ₹{{ '%.0f'|format(price) }} {% endfor %}

Sorted price sequence shown for demonstration. Insertion sort worst-case time complexity is O(n²).
